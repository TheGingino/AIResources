# What is this game about?
The game features a human going through scenarios of everyday life people that work on a desk with a computer.
You got to respond to specific emails or other info with the use of AI or you do it yourself.


## Necessary commands to connect with AI
The Commands that you need to put in the cmd to make ollama work with Unity:
- ollama pull llama3
- ollama serve
